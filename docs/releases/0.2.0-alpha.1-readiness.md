# Replica 0.2.0 Alpha 1 readiness

## Scope

This candidate adds the macOS 13+ read-only Preview and multi-platform GitHub Release packaging. Windows 11 x64 remains the full migration/recovery client. macOS ARM64 and x64 provide environment scanning, Lightweight Snapshot creation/validation, Snapshot inspection, and Release lookup without system mutation.

## Build and tests

- Local Windows restore, formatting, Release build, and all 363 automated tests pass with zero compiler warnings.
- Windows `ReplicaSetup-0.2.0-alpha.1.exe` builds successfully and its SHA-256/package contract passes.
- Local cross-publish produces self-contained `osx-arm64` and `osx-x64` single-file executables.
- `actionlint` accepts CI, CodeQL, and Release workflow syntax.
- PR CI must additionally create and checksum an ARM64 DMG on `macos-latest`; the tag workflow must create and checksum both ARM64 and x64 DMGs before publication.

## Security

- The Mac scanner is read-only and uses fixed Homebrew operations with timeout, cancellation, bounded output, and no shell evaluation.
- Sensitive environment values, Keychain data, browser profiles, broad Library data, and user files are excluded.
- The Snapshot reader retains traversal, duplicate-entry, link/reparse, compression, size, JSON, and checksum defenses on both platforms.
- The Windows recovery wizard rejects a Snapshot whose source platform is not Windows. The Mac app registers no restore, elevation, registry, environment-write, or rollback handlers.
- Release assets are checksummed and receive GitHub provenance attestations when supported.

## Experimental and known issues

- macOS is Preview scope, not feature parity with Windows recovery.
- Recovery Snapshot creation, encrypted-Snapshot password entry, Diff Restore, execution, rollback, and in-app DMG installation are not implemented in the Mac UI.
- Mac packages are ad-hoc signed and not Apple Developer ID signed or notarized. Gatekeeper may require explicit Finder confirmation.
- A human launch/accessibility check on representative Apple Silicon and Intel hardware is still recommended; CI validates compilation, bundle structure, code-signature integrity, DMG creation, and hashes but is not a full interactive UX test.
- Windows remains unsigned until an Authenticode certificate is configured.

## Release decision

Conditionally ready for an Alpha release only after the focused PR is merged with successful Windows CI, macOS CI, and CodeQL checks. A failed Mac DMG build, checksum mismatch, test failure, or Critical security finding blocks the tag. These limitations block Stable status but do not misrepresent the explicitly labeled Alpha Preview.
