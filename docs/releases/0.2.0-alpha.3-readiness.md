# Replica 0.2.0 Alpha 3 readiness

## Candidate

- Version: `0.2.0-alpha.3`
- Intended tag: `v0.2.0-alpha.3`
- Channel: GitHub pre-release
- Platforms: Windows 11 x64 recovery client; macOS 13+ ARM64/x64 read-only Preview

## Scope

Alpha 3 supersedes the unpublished Alpha 2 candidate without moving its immutable tag. It contains the same production-quality recovery work and adds the release-automation compatibility fixes discovered by the two fail-closed Alpha 2 workflow attempts.

The first attempt exposed mixed UTF-8/UTF-16 GitHub output caused by Windows PowerShell 5.1 shell redirection. The second reached authenticated Inno input validation and exposed unavailable modern .NET path/hash APIs. Both failures occurred before an official GitHub Release or partial release Asset was published.

## Verification

- Pull requests #34, #35, and #36 passed their required Windows, macOS ARM64/x64, and CodeQL checks.
- The product suite passed 457 tests on the final production-quality change.
- Release version, documentation, PowerShell parser, formatting, build, test, vulnerability-audit, macOS packaging, and CodeQL checks are rerun for this candidate.
- GitHub environment/output files use explicit BOM-less UTF-8 writes.
- The Inno directory digest and certificate-digest paths run under Windows PowerShell 5.1 without `Path.GetRelativePath`, `Convert.ToHexString`, or static `SHA256.HashData`.
- The reviewed Inno Setup 6.7.1 artifact is pinned by its deterministic tree digest and valid Pyrsys B.V. signer-certificate digest.

## Trust posture and known limitations

- This Alpha may publish an unsigned Windows installer and ad-hoc-signed, non-notarized macOS DMGs only with prominent trust notes and matching SHA-256 files.
- Stable remains blocked until Windows Authenticode and Apple Developer ID signing/notarization succeed with reviewed public certificate pins.
- macOS remains a read-only Preview without restore execution or rollback.
- Clean Windows 11 VM recovery/rollback/install validation and representative Mac interactive accessibility checks remain human validation work.
- No project license has been selected; public source availability is not an open-source license grant.

## Release decision

Ready for the `v0.2.0-alpha.3` GitHub pre-release only after this focused fix is merged and every required CI check passes. The release workflow must still publish nothing if any build, package, checksum, provenance, or trust validation fails.
